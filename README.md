# Hybrid-Unsupervised-Ensemble-Architecture-for-Hyper-Local-Soil-Nutrient-Depletion-Forecasting
A hybrid ML system for hyper-local soil nutrient depletion forecasting. Combines PCA, K-Means clustering, feature engineering, and ensemble models like Random Forest, XGBoost, CatBoost, and LightGBM to predict soil nutrient trends and support data-driven smart farming decisions.
